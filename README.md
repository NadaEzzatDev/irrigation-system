# Mini Irrigation System – Wiring Story

An interactive website that teaches Grade 7 students how to wire an Arduino irrigation system, step by step, as a story.

It starts by showing all the components. Then, at each step, it asks students a question, such as "Can the Arduino run the pump by itself?" After students answer, it adds the next wires and explains why they are needed. At the end, students can try the whole system with a soil moisture slider and use a checklist of all the connections.

**Components:** Arduino UNO, soil moisture sensor, water pump, L298N H-Bridge, 9V battery, breadboard and jumper wires.
